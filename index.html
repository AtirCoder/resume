01 — SYSTEMS ENGINEERING
FROM BITS TO A RUNNING SYSTEM↗

Mini RISC-V指令级模拟器与微型操作系统

C / RISC-V / PYTHON
项目细节 ＋

打通从可执行文件到用户态程序的运行链路，再用差分验证检查系统行为。

  • 实现 RV32I 基础 40 条指令、6 类 CSR 指令及 MRET，连接 ELF32 装载、系统总线、UART 与定时器。
  • 围绕 M/U 特权切换与 trap 上下文恢复，构建定时器中断驱动的三进程轮转，提供 read / write / yield / exit 系统调用、bump 分配器与交互式 Shell。
  • 实现组相联 Cache、真 LRU、写回与写分配；通过直连 DRAM / Cache 双路径集成测试和随机访存对拍验证一致性。
02 — NETWORK & CONCURRENCY
REQUEST. ROUTE. RESPOND.↗

HTTP Proxy并发代理与对象缓存

C / POSIX / SOCKET
项目细节 ＋

基于课程框架研究应用层协议、连接级并发与共享缓存的边界。

  • 梳理 HTTP 请求解析、主机与端口提取、连接头重写及响应转发，结合缓冲 I/O 理解字节流与消息的边界。
  • 采用每连接一线程的模型，通过线程分离和独立参数传递组织会话，分析连接、读写与描述符释放的生命周期。
  • 结合请求哈希索引、时间戳与 LRU 组织定长对象缓存，分析信号量读者–写者模型及缓存临界区。
03 — CREATIVE COMPUTING
CURVE → SURFACE → MATERIAL↗

Parametric Forms参数化几何与程序化材质

C++ / OPENGL / GLSL
项目细节 ＋

把曲线、网格和着色逻辑连接成可交互的渲染流程。

  • 用三次 Bézier 曲线构造花瓶旋转曲面，以解析导数计算法线；参数化生成花瓣、萼片与唇瓣，组织索引网格和场景变换。
  • 在 GLSL 中结合极坐标纹样、fBm 噪声与 Blinn–Phong 光照，模拟瓷器纹理、花瓣脉络与近似透光效果。
  • 基于 OpenGL 3.3 实现渲染，支持轨道相机旋转与缩放。
