# 蔡鸿海 · 从抽象到实现

以 Lusion 的浅灰页面、深色视觉窗口和蓝黑白空间语言为参考，基于原简历重构的响应式个人网站。所有个人经历与成绩来自仓库原有的 `resume.pdf`。

## 内容与操作

- 原创 Three.js 参数化雕塑，支持指针轻微视角反馈、播放 / 暂停。
- 三个项目采用原创 AI 生成的蓝银色 3D 概念配图与原生可展开详情；配图明确标注非运行截图。
- 教育、成绩、技能、荣誉及邮件 / 电话 / GitHub 联系入口。
- 保留原 PDF，可直接查看和下载。
- 支持手机布局、键盘操作、减少动态效果偏好及打印。
- WebGL 或模块加载失败时显示静态构图；场景离开视口或切换后台时停止动画。

## 部署

仓库根目录是完整静态站点，无需安装依赖或构建。通过 HTTP 静态服务器预览，或使用现有的 GitHub Pages 根目录发布配置。请勿直接用 `file://` 打开，浏览器会限制 ES 模块加载。

合并到 `main` 后，现有 GitHub Pages 配置会发布此页面。

## 维护

- `index.html`：简历内容和语义结构。
- `style.css`：布局、响应式、减少动态效果与打印样式。
- `app.js`：菜单与项目深链接。
- `assets/`：三张本地 WebP 项目概念配图。
- `scene.js`：首屏原创几何、灯光、动画和降级逻辑。
- `resume.pdf`：保留的原简历。
- `vendor/`：本地 Three.js 0.186.1 与 MIT 许可证，不依赖外部 CDN。

原页面的 `noindex,nofollow` 设置已保留。没有引入追踪、表单后台或外部字体。
